Signature Generation
Step 1: Prepare params merchant_id, amount, merchant_order_no, callback_url

Step 2: Remove empty values

Step 3: Sort alphabetically
amount → callback_url → merchant_id → merchant_order_no

Step 4: Build string
amount=1000.00&callback_url=https://site.com/callback&merchant_id=MERCH1001&merchant_order_no=ORD20250201

Step 5: Append API key
amount=1000.00&callback_url=https://site.com/callback&merchant_id=MERCH1001&merchant_order_no=ORD20250201&key=API_KEY

Step 6: MD5 hash → signature
• Amount must always have 2 decimals
• Do not URL encode callback_url
• Sorting is mandatory

PHP Signature Example

<?php

$merchant_id = "100555001";
$api_key = "sk_live_xxx";

$amount = number_format(1000,2,'.','');
$merchant_order_no = "ORD20250201";
$callback_url = "https://site.com/callback";

$params = [
    "merchant_id" => $merchant_id,
    "amount" => $amount,
    "merchant_order_no" => $merchant_order_no,
    "callback_url" => $callback_url
];

$params = array_filter($params);
ksort($params);

$signStr = "";

foreach($params as $k=>$v){
    $signStr .= $k."=".$v."&";
}

$signStr .= "key=".$api_key;

$signature = md5($signStr);

echo $signature;

?>
