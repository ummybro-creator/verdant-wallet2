Create Payment Order API
API Endpoint
POST https://api.bond-payss.com/v1/create
Content-Type: application/json
Request Parameters
Field	Type	Description	Example
merchant_id	string	Your unique merchant ID	100888001
api_key	string	API key for authentication	abc123xyz456
amount	float/string	Amount to collect in INR	500.00
merchant_order_no	string	Unique order number generated by merchant	ORDER_1761272941_4849
callback_url	string	URL to receive payment status updates	https://merchant.example.com/callback
extra	int/string	Optional field for reference	0
signature	string	MD5 hash for request validation	c923010a8a889d5b61d96b11be2aac83
Signature Creation
The signature is generated using MD5 hash:

md5( merchant_id + amount + merchant_order_no + api_key + callback_url )
Example:

merchant_id = 100888001
amount = 500.00
merchant_order_no = ORDER_1761272941_4849
api_key = abc123xyz456
callback_url = https://merchant.example.com/callback

Payment Callback API
BondPay will send payment status updates to your callback URL via POST request with JSON payload.

Callback Request
POST Your Callback URL
Content-Type: application/json
Callback Parameters
Field	Type	Description	Example
orderNo	string	BondPay system order number	20251105205347935010403
merchantOrder	string	Your merchant order number	ORDER_1762356226_7932
status	string	Payment status	success
amount	float	Payment amount	200
createtime	string	Order creation timestamp (ISO 8601)	2025-11-05T20:53:47.937067
updatetime	string	Order update timestamp (ISO 8601)	2025-11-05T20:54:22.041635
Status Values
Status	Description	Action
success	Payment completed successfully	Deliver product/service
pending	Payment is being processed	Wait for final status
failed	Payment failed or was cancelled	Inform user and retry
Example Callback Payload
{
    "orderNo": "20251105205347935010403",
    "merchantOrder": "ORDER_1762356226_7932",
    "status": "success",
    "amount": 200,
    "createtime": "2025-11-05T20:53:47.937067",
    "updatetime": "2025-11-05T20:54:22.041635"
}
Callback Response Expected
Your server should respond with HTTP 200 status and a JSON response:

{
    "status": "ok",
    "message": "Callback received successfully"
}
Notes
Use order_no to track payment status.
Redirect users to payment_url to complete payment.
Verify callback signature for security (if provided).
Use HTTPS endpoints only.
Keep your API key secure and never expose it in client-side code.
Implement idempotency in your callback handler to handle duplicate callbacks.
Log all callback requests for debugging and audit purposes.
Respond quickly to callbacks (within 2-3 seconds) to avoid timeouts.
